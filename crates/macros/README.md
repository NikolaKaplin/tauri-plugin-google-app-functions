# tauri-plugin-google-app-functions-macros

Procedural macros for
[tauri-plugin-google-app-functions](https://crates.io/crates/tauri-plugin-google-app-functions):
`#[app_function]` and `#[app_function_serializable]`.

Don't depend on this crate directly: the plugin re-exports both macros.

```rust
use tauri_plugin_google_app_functions::{app_function, app_function_serializable};
```

See the [plugin's README](https://github.com/NikolaKaplin/tauri-plugin-google-app-functions#readme)
for setup and usage.
